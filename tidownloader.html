DESPLIEGUE RÁPIDO

Cómo Iniciar TiDownloader en 2 Minutos

Elige el método que mejor se adapte a tu entorno:

01

Clona el Repositorio

git clone https://github.com/JaviLabarumDJ/tidownloader.git
cd tidownloader

02

Inicia con Docker

Ejecuta el contenedor en segundo plano:
docker compose up -d

03

Abre el Navegador

Entra en http://localhost:8000, vincula tu cuenta y empieza a descargar tus pistas en máxima calidad.

DUDAS FRECUENTES

Preguntas Frecuentes

¿Necesito una suscripción de Tidal? +

Sí, TiDownloader utiliza la API oficial de Tidal y requiere que vincules tu cuenta activa de Tidal para descargar los archivos que tu suscripción permite.

¿Puedo pasar los temas descargados a mi móvil para Mixxx? +

¡Claro! Los archivos descargados quedan almacenados en la carpeta que elijas en tu ordenador o NAS. Puedes copiarlos a la memoria de tu móvil o a un pendrive USB OTG y cargarlos directamente en Mixxx DJ para Android.
